Project: Python - Pie Chart
==================================

Introduction
------------

This is my invented code for Learning Journal unit 2 in CS 1101-01 Programming Fundamentals (University of The People). This project is an opportunity for me to demonstrate the concepts I learned in the unit:
* Function
* Variable
* Expression
* Statement

Description
-----------

I created a function that count the number of people who work in certain occupation based on each degree in a pie chart. This function let me manipulate variables. I put "degree" and "totalAmount" as the argument to count the number of people who work in a certain occupation. For example. in a pie chart, the developers occupied 20 degrees of it. So I want to be able to count the number of developers in the company using this function.  I also put "occupation" as the argument, so I can put the occupation that I want to count. From this function, I learnt that I don't have to put any type of a variable when declaring a variable, for example: int variable.
